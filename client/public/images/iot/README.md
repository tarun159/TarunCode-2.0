# IoT Circuit Diagrams

Place your circuit diagram images here and overwrite the placeholders.

- Filenames referenced from `client/src/data/programs.ts`: `circuit-01.png` … `circuit-10.png`
- Recommended: large, responsive images (e.g. 1200×675 or wider, transparent or dark background).
- These are referenced at the public root path `/images/iot/circuit-0X.png`.
- The placeholder PNGs are just dark solid images so the page renders before you add real diagrams.
